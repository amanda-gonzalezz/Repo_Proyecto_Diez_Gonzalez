# El primer lugar de la lista no asegura la elección

## Tema

La posición que ocupaban las candidaturas electas dentro de sus listas en las elecciones de consejeros regionales (CORE) de Chile en 2024.

## Descripción

Este sitio web presenta una crónica sobre la relación entre la posición de las candidaturas dentro de sus listas y los resultados de las elecciones CORE 2024.

La página integra la crónica de la Entrega 03 y una visualización de datos que compara, por región, el porcentaje de personas electas que ocupaban la primera posición y aquellas que estaban en otras posiciones.

## Proceso

Primero organicé el contenido a partir de mi crónica individual de la Entrega 03. Después estructuré la página en HTML, utilizando etiquetas como `head`, `body`, `h1`, `p`, `img` y `a`.

Incorporé la imagen del gráfico en su versión interactiva para poder ver mejor los datos.

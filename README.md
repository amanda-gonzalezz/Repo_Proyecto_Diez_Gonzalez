# Proyecto Narración Gráfica

Este repositorio reúne las distintas entregas y avances de nuestro proyecto sobre la elección de Consejeros Regionales (CORE) de 2024.

El proyecto busca analizar la relación entre la posición que ocupa una candidatura dentro de su lista y sus resultados electorales, considerando también el gasto realizado durante la campaña.
